📐 3. Minimized Boolean Equations

Simplified using Karnaugh Maps (K-Maps) taking inputs 10–15 as don't-cares, then converted to universal NAND form via De Morgan's theorem:

W (Bit 3) A + BC + BD = NAND(A', (BC)', (BD)')
X (Bit 2) B'C + B'D + BC'D' = NAND((B'C)', (B'D)', (BC'D')')
Y (Bit 1) CD + C'D' = NAND((CD)', (C'D')')
Z (Bit 0) D' = NAND(D, D)

Viva Voce: Why is Excess-3 a Self-Complementing Code?
Excess-3 is self-complementing because the 9's complement of a decimal digit corresponds directly to the 1's complement of its Excess-3 code. This property significantly simplifies 9's complement subtraction in computer arithmetic logic units (ALU).
Viva Voce: Why use only NAND Gates?
NAND is a universal gate. Any basic logic operation (NOT, AND, OR, NOR, XOR, XNOR) can be fabricated using only NAND gates, reducing IC inventory and fabrication costs on breadboards or silicon dies.
