3. Boolean expressions

W = A + BC + BD
X = B'C + B'D + BC'D'
Y = CD + C'D'
Z = D'

These equations are minimized using don't-care input codes 1010–1111. The actual implementation uses NAND operations exclusively.

4. Practical steps

  1. Select decimal digits 0 through 9.
  2. Observe BCD input A B C D.
  3. Verify NAND network outputs W X Y Z.
  4. Compare results with the truth table.
  5. Record the result: Excess-3 = BCD + 0011.
